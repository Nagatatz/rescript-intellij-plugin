// The Kotlin compiler option `-jvm-default=no-compatibility` (see
// build.gradle.kts) removes the DefaultImpls bridge methods that used to
// reference deprecated Java-interface default methods. Bridge-method
// entries that were previously listed here (ToolWindowFactory.isApplicable,
// ToolWindowFactory.isDoNotActivateOnStart, the
// ProjectViewNodeDecorator.decorate(PackageDependenciesNode, …) overload,
// StatusBarWidget.getPresentation(PlatformType), StatusBarWidget.PlatformType)
// are no longer needed. Do not re-add them without first checking that the
// compiler flag still eliminates the corresponding bytecode references.

// ── Internal API exceptions ──────────────────────────────────────────
// CodeVisionPlaceholderCollector — listed as an exception on the JetBrains
// Internal API Migration page: "Made public in 2024.2"
// https://plugins.jetbrains.com/docs/intellij/api-internal.html
// The @Internal annotation remains in bytecode, so the verifier still flags it
// even though JetBrains officially permits third-party usage.
// Status: KEEP — annotation not yet removed from source.
com\.rescript\.plugin:.*:.*CodeVisionPlaceholderCollector.*
