# 要求定義書: A 優先度機能実装

## 概要

ロードマップの A 優先度に分類された 13 機能を実装する。Intention Actions を中心に、ナビゲーション、補完、InlayHints、Generate、Quick Fix、Editor 連携の各カテゴリにわたる。

## 対象機能一覧

| # | 機能 | カテゴリ | 難易度 |
|---|------|---------|--------|
| 46 | Search Everywhere | ナビゲーション | 中 |
| 49 | Unresolved Reference Quick Fix | Quick Fix | 中〜高 |
| 50 | Completion Weigher | 補完 | 中 |
| 74 | パイプチェーン中間型ヒント | InlayHints | 中 |
| 75 | ラベル付き引数の一括挿入 | Intention | 中 |
| 77 | Make 関数生成 | Generate | 中 |
| 78 | Switch ケース統合 | Intention | 中 |
| 89 | 使用箇所からの関数生成 | Quick Fix | 中〜高 |
| 94 | .resi シグネチャ同期 | Editor | 中 |
| 95 | ケースの変数分割 | Intention | 中 |

| 100 | 不要な括弧の削除 | Intention | 中 |
| 101 | 不要な修飾子の削除 | Intention | 中 |

## 機能要件

### #46 Search Everywhere

**概要:** ファイル・シンボルの統合検索に ReScript シンボルを含める。

**受け入れ条件:**
- [ ] Search Everywhere (Shift+Shift) で ReScript のトップレベル宣言（let, type, module, external, exception）が検索できる
- [ ] 検索結果に適切なアイコンとファイル位置が表示される
- [ ] 結果選択で該当箇所にジャンプできる

### #49 Unresolved Reference Quick Fix

**概要:** 未解決の識別子に対して、`open` 文の追加や完全修飾パスの提案を行う。

**受け入れ条件:**
- [ ] 未解決の識別子にカーソルを置いて Alt+Enter で候補が表示される
- [ ] `open ModuleName` の挿入候補を提案する
- [ ] 完全修飾パス（`ModuleName.identifier`）への変換を提案する
- [ ] `RescriptOpenStatementIndex` を活用してプロジェクト内モジュールを検索する

### #50 Completion Weigher

**概要:** 補完候補の表示順序をコンテキストに応じて最適化する。

**受け入れ条件:**
- [ ] ローカルスコープの変数が優先表示される
- [ ] 現在のファイルで `open` されているモジュールの要素が優先される
- [ ] 型が一致する候補が上位に表示される（LSP 情報が利用可能な場合）
- [ ] 使用頻度の高い補完候補が上位に表示される

### #74 パイプチェーン中間型ヒント

**概要:** パイプチェーン `->` の各ステップで中間型をインライン表示する。

**受け入れ条件:**
- [ ] パイプチェーンの各 `->` の後に中間型がインレイヒントで表示される
- [ ] LSP hover を使用して型情報を取得する
- [ ] 表示/非表示を設定で切り替えられる
- [ ] パフォーマンスに影響しないよう非同期で処理する

### #75 ラベル付き引数の一括挿入

**概要:** 関数呼び出しにラベル付き引数のプレースホルダーを一括挿入する。

**受け入れ条件:**
- [ ] 関数呼び出しにカーソルを置いて Alt+Enter で「Insert labeled arguments」が表示される
- [ ] LSP hover から関数シグネチャを取得し、ラベル付き引数を解析する
- [ ] 省略可能引数（`~arg=?`）とオプション引数を区別する
- [ ] 挿入後、最初の引数にカーソルが移動する

### #77 Make 関数生成

**概要:** レコード型からコンストラクタ関数（make 関数）を自動生成する。

**受け入れ条件:**
- [ ] レコード型定義にカーソルを置いて Cmd+N > Generate で「Generate make function」が表示される
- [ ] レコードの全フィールドをラベル付き引数として持つ関数が生成される
- [ ] mutable フィールドと immutable フィールドを正しく処理する
- [ ] オプションフィールド（`option` 型）にデフォルト値 `=?` を設定する

### #78 Switch ケース統合

**概要:** 同じボディを持つ switch ケースを `| A | B => body` 形式に統合する。

**受け入れ条件:**
- [ ] 同一ボディの switch ケースが存在するとき Alt+Enter で「Merge switch cases」が表示される
- [ ] 統合後の形式が `| Pattern1 | Pattern2 => body` となる
- [ ] 隣接していないケースも統合できる（間のケースを並べ替える）
- [ ] ワイルドカードパターン `_` を含むケースは統合対象外とする

### #89 使用箇所からの関数生成

**概要:** 未定義の関数呼び出しからスタブ関数を生成する。

**受け入れ条件:**
- [ ] 未定義の関数名にカーソルを置いて Alt+Enter で「Generate function」が表示される
- [ ] 呼び出し箇所の引数から仮引数を推定する
- [ ] 生成先はカーソル位置の直前のトップレベル宣言の後とする
- [ ] 生成後のカーソルは関数ボディに移動する

### #94 .resi シグネチャ同期

**概要:** `.res` の宣言変更を対応する `.resi` に自動同期する。

**受け入れ条件:**
- [ ] `.res` ファイルの宣言を変更した際に `.resi` との差分を検出する
- [ ] 変更があった場合、通知またはインスペクションで同期を促す
- [ ] ワンクリックで `.resi` のシグネチャを更新できる
- [ ] LSP の `textDocument/createInterface` を活用する

### #95 ケースの変数分割（Case Split）

**概要:** switch のパターン変数を全コンストラクタに展開する。

**受け入れ条件:**
- [ ] switch のパターン変数にカーソルを置いて Alt+Enter で「Split into cases」が表示される
- [ ] 変数の型が variant 型の場合、全コンストラクタのパターンに展開する
- [ ] ペイロード付きコンストラクタには `_` プレースホルダーを挿入する
- [ ] LSP hover で型情報を取得する

### #98 位置引数→ラベル付き引数

**概要:** 関数呼び出しの位置引数をラベル付き引数に変換する。

**受け入れ条件:**
- [ ] 関数呼び出しにカーソルを置いて Alt+Enter で「Convert to labeled arguments」が表示される
- [ ] LSP hover から関数シグネチャのラベル名を取得する
- [ ] `foo(1, "hello")` → `foo(~id=1, ~name="hello")` の形式に変換する
- [ ] すでにラベル付きの引数はスキップする

### #100 不要な括弧の削除

**概要:** 式を囲む不要な括弧を検出して削除する。

**受け入れ条件:**
- [ ] 不要な括弧にカーソルを置いて Alt+Enter で「Remove unnecessary parentheses」が表示される
- [ ] 関数呼び出しの引数を囲む単一の括弧は不要と判定する
- [ ] 演算子の優先順位で必要な括弧は削除対象外とする
- [ ] JSX 属性内の括弧 `prop={value}` は削除対象外とする

### #101 不要な修飾子の削除

**概要:** `open` で展開済みのモジュールパスの冗長な修飾子を削除する。

**受け入れ条件:**
- [ ] 冗長な修飾子にカーソルを置いて Alt+Enter で「Remove redundant qualifier」が表示される
- [ ] ファイル内の `open` 文を解析し、展開済みモジュールを判定する
- [ ] `Array.map` で `open Array` がある場合に `map` に短縮する
- [ ] 名前衝突がある場合は削除対象外とする

## 非機能要件

- Intention の `isAvailable()` は軽量に実装し、エディタの入力遅延に影響しないこと
- LSP 通信が必要な機能は、LSP サーバー未起動時に graceful に無効化すること
- InlayHints は非同期処理でバックグラウンドスレッドから提供すること
