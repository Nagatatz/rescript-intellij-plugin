# Requirements: Project Wizard Templates

## Overview
Expand the ReScript project wizard from 2 templates to 12 templates covering major use-case domains.

## Templates
| # | Template | Category |
|---|----------|----------|
| 1 | Basic | Basic |
| 2 | Vite + React | Frontend |
| 3 | Next.js | Frontend |
| 4 | Electron | Desktop |
| 5 | Hono (Node.js) | Backend |
| 6 | Cloudflare Workers | Serverless |
| 7 | AWS Lambda | Serverless |
| 8 | Google Cloud Run | Serverless |
| 9 | React Native (Expo) | Mobile |
| 10 | npm Library | Library |
| 11 | CLI Tool | Tool |
| 12 | Monorepo (Hono + React) | Full Stack |

## Acceptance Criteria
- All 12 templates generate valid project files
- Wizard UI shows template list with categories and descriptions
- Package manager selection retained
- Unit tests cover all templates
