# Requirements: Claude 設定ダイエット

## 目的

ベストプラクティスレポート（`.steering/20260221-006-claude-code-best-practices/report.md`）の知見に基づき、CLAUDE.md と Rules ファイルを最適化してコンテキスト消費を削減し、指示遵守率を向上させる。

## 背景

- CLAUDE.md: 466行（推奨は300行以下、理想は200行以下）
- steering-workflow.md: 229行（テンプレート・手順の詳細が大量）
- documentation.md: 237行（draw.io MCP の例示が大量）
- 合計 Rules: 638行
- レポートの知見: 「長すぎると全指示に対して均一にパフォーマンスが低下する」

## 要件

### A1: CLAUDE.md ダイエット（466行 → 200行以下）

- プロジェクト構成図（約150行のファイルツリー）を外部ファイルに移動し `@` 参照に
- ロードマップ/将来実装予定（約100行）を外部ファイルに移動し `@` 参照に
- Rules に既に記載済みの開発規約詳細を削除し `@` 参照のみ残す
- 残す内容: 概要 + ビルドコマンド + アーキテクチャ概要 + 重要な注意事項 + 参照リンク

### A2: Rules スリム化

- `steering-workflow.md`（229行）: テンプレート・フォーマット例を削除し原則のみ残す（目標50行以下）
- `documentation.md`（237行）: draw.io の表・例示を削除し原則のみ残す（目標50行以下）
- テンプレート・詳細手順は既存の Skills 内に移動

### A3: コンパクション指示の追加

- CLAUDE.md にコンパクション時の保持内容を明記
- 現在のブランチ、worktree パス、steering ディレクトリ、変更ファイル一覧

### A4: セキュリティプロンプトの追加

- CLAUDE.md にセキュリティ指示セクションを追加
- IntelliJ Platform プラグイン開発に特化した内容

## 受け入れ条件

- CLAUDE.md が200行以下
- steering-workflow.md が50行以下
- documentation.md が50行以下
- 既存の指示内容が失われていない（外部ファイルまたは Skills に移動済み）
- `./gradlew buildPlugin` が成功する（設定変更のみなのでビルドへの影響なし）
