# 要求: パフォーマンス調査

## 目的

大規模プロジェクト（100+ .res ファイル）でのプラグインパフォーマンス特性を調査し、潜在的なボトルネックを特定する。

## 調査対象

1. インデックス構築・シンボル検索のスケーラビリティ
2. 外部プロセス起動のタイムアウト設定の網羅性
3. UI スレッド（EDT）ブロッキングのリスク
4. メモリ使用パターン（キャッシュ、リーク）

## 受け入れ条件

- [ ] パフォーマンスボトルネックが文書化されている
- [ ] 各ボトルネックの深刻度と影響範囲が評価されている
- [ ] 発見されたバグ（タイムアウト欠落等）が記録されている
