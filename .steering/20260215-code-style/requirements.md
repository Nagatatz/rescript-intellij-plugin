# requirements.md - インデント・コードスタイル

## 概要

ReScript IntelliJ プラグインにインデント（スマートインデント）とコードスタイル設定機能を追加する。ユーザーが Enter キーを押した際に適切なインデントレベルが自動設定され、IDE の Settings UI からインデント設定をカスタマイズできるようにする。

## 背景

現在のプラグインにはインデント・コードスタイル関連の機能が一切実装されていない。Enter キーを押しても前の行のインデントが維持されるだけで、ブレース内やアロー関数の後でインデントレベルが増加しない。ReScript は 2 スペースインデントが標準であるが、IDE のデフォルト設定が適用されてしまう。

## ユーザーストーリー

### US-CS-01: スマートインデント

**ユーザーとして**、Enter キーを押した際にコンテキストに応じたインデントレベルが自動設定されることで、手動でスペースを入力する手間を省きたい。

**受け入れ条件:**
- [ ] `{` の後で Enter を押すと、次の行が 1 レベルインデントされる
- [ ] `(` の後で Enter を押すと、次の行が 1 レベルインデントされる
- [ ] `[` の後で Enter を押すと、次の行が 1 レベルインデントされる
- [ ] `=>` の後で Enter を押すと、次の行が 1 レベルインデントされる
- [ ] `}` / `)` / `]` のみの行は親ブロックのインデントレベルに戻る
- [ ] それ以外の場合は前の行のインデントを維持する

### US-CS-02: ブレース間の Enter 動作

**ユーザーとして**、`{|}` の間で Enter を押した際にブレースが分割され、カーソルがインデントされた新しい行に配置されることで、ブロック構造を素早く入力したい。

**受け入れ条件:**
- [ ] `{|}` の間で Enter を押すと `{\n  |\n}` になる
- [ ] `(|)` の間で Enter を押すと `(\n  |\n)` になる
- [ ] `[|]` の間で Enter を押すと `[\n  |\n]` になる

### US-CS-03: コードスタイル設定 UI

**ユーザーとして**、IDE の Settings > Editor > Code Style > ReScript からインデント設定をカスタマイズできることで、チームの規約に合わせた設定を行いたい。

**受け入れ条件:**
- [ ] Settings > Editor > Code Style に「ReScript」タブが表示される
- [ ] 「Tabs and Indents」タブでインデントサイズ、タブ/スペース選択、継続インデントサイズを設定できる
- [ ] デフォルト値: インデントサイズ 2、スペース使用、継続インデントサイズ 2
- [ ] 設定変更がエディタに即座に反映される

## 技術的制約

- **軽量パーサーの制約**: 現在のパーサーはトップレベル宣言のみを認識する。式レベルの PSI ツリーがないため、`FormattingModelBuilder` による完全なフォーマッティングは実現困難
- **LSP フォーマッティング**: ドキュメント全体のリフォーマット（Ctrl+Alt+L）は LSP の `textDocument/formatting` が担当するため、プラグイン側での `FormattingModelBuilder` 実装は不要
- **`LineIndentProvider`**: PSI ツリーに依存せず、エディタのドキュメントテキストから直接インデントを計算できるため、現在のアーキテクチャに最適
- **`EnterBetweenBracesDelegate`**: 既存の `BraceMatcher` と連携してブレース分割を実現できる

## スコープ

### 含まれるもの
- `LineIndentProvider` によるスマートインデント（Enter キー）
- ブレース間の Enter 動作（`EnterBetweenBracesDelegate`）
- コードスタイル設定 UI（`LanguageCodeStyleSettingsProvider`）
- ReScript デフォルトインデント設定（2 スペース）

### 含まれないもの
- `FormattingModelBuilder` によるリフォーマット（LSP に委譲）
- スペーシングルール（演算子周りのスペース等）
- ブランクライン管理
- コード折り返し（ラッピング）ルール
