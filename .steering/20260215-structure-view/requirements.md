# Requirements: Structure View

## 概要

ReScript ファイルの構造をサイドバー（Structure Tool Window）にツリー表示する機能を実装する。
既存の軽量パーサーが生成する PSI ツリーを活用し、トップレベル宣言の一覧をナビゲーション可能な形で表示する。

## ユーザーストーリー

- 開発者として、ReScript ファイル内のトップレベル宣言（let, type, module, external, exception）をサイドバーで一覧表示したい。ファイルの全体構造を素早く把握するため。
- 開発者として、Structure View のアイテムをクリックして、該当箇所にジャンプしたい。大きなファイルでの移動を効率化するため。
- 開発者として、module 内のネストされた宣言を階層表示で確認したい。モジュール構造を理解するため。

## 機能要件

### 表示する宣言の種類

| 宣言種別 | 表示名の例 | アイコン |
|---------|-----------|---------|
| `let` 宣言 | `let add` | IntelliJ 標準の Function アイコン |
| `type` 宣言 | `type user` | IntelliJ 標準の Class/Type アイコン |
| `module` 宣言 | `module Utils` | IntelliJ 標準の Module アイコン |
| `external` 宣言 | `external log` | IntelliJ 標準の Function アイコン（区別マーク付き） |
| `exception` 宣言 | `exception NotFound` | IntelliJ 標準の Exception アイコン |

### 表示しない要素

- `open` 文
- `include` 文
- `@` アノテーション（親要素の付加情報として扱う）

### 階層構造

- ファイルルートの直下にトップレベル宣言を表示
- `module` 宣言はネストされた子宣言を持つ場合、展開可能なツリーノードとして表示

### ナビゲーション

- ツリーアイテムをクリック/ダブルクリックで、エディタの該当行にジャンプする

### ソート

- IntelliJ 標準のアルファベット順ソートに対応する

## 非機能要件

- パーサーのリビルドは不要（既存の PSI ツリーをそのまま利用）
- ファイル編集時にリアルタイムで Structure View が更新される（IntelliJ Platform の標準動作に依存）
- パフォーマンスへの影響を最小限にする（大きなファイルでも高速に表示）

## 受け入れ条件

1. `Alt+7`（macOS: `Cmd+7`）で Structure Tool Window を開くと、ReScript ファイルの宣言一覧が表示される
2. 各宣言に適切なアイコンと名前が表示される
3. ツリーアイテムクリックでエディタの該当箇所にカーソルが移動する
4. アルファベット順ソートが機能する
5. ビルドが正常に通る

## 制約事項

- 既存の軽量パーサーはトップレベル宣言のみ認識するため、関数内のローカル let バインディングなどは表示対象外
- `module` 内のネスト表示は、パーサーが `module` 内部の宣言を再帰的にパースしている場合にのみ対応可能（現在のパーサーの `skipToEndOfDeclaration` の挙動による）
