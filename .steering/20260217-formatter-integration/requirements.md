# Requirements: フォーマッタ連携

## 概要

ReScript のコードフォーマッタ（`rescript format`）を IntelliJ のフォーマットアクション（`Cmd+Option+L`）から呼び出せるようにする。

## 背景

現在、ReScript コードのフォーマットは LSP のドキュメントフォーマットに依存しているが、LSP 未起動時や、明示的にフォーマットコマンドを実行したい場合に利用できない。`rescript format` CLI は stdin からコードを受け取り、フォーマット済みコードを stdout に出力する。

## 機能要件

### F1: フォーマットアクションの統合

- `Cmd+Option+L`（Reformat Code）で `rescript format` CLI が実行されること
- フォーマット対象は現在開いている `.res` / `.resi` ファイル
- フォーマット結果でエディタ内容が置換されること
- Undo で元に戻せること

### F2: CLI 検出

- プロジェクトの `node_modules/.bin/rescript` を優先的に使用
- 見つからない場合は PATH 上の `rescript` を使用
- どちらも見つからない場合はエラー通知を表示

### F3: エラーハンドリング

- フォーマットに失敗した場合（構文エラー等）、元のコードを維持すること
- エラーメッセージをユーザーに通知すること

## 非機能要件

- フォーマット処理はバックグラウンドスレッドで実行すること
- 既存のテスト・ビルドを壊さないこと

## 受け入れ条件

- [ ] `Cmd+Option+L` で ReScript コードがフォーマットされる
- [ ] `rescript` CLI が見つからない場合にエラー通知が出る
- [ ] 構文エラーのあるコードでフォーマット失敗時に元のコードが維持される
- [ ] ビルドが通る
