## 方針

### KDoc コメント

- 各クラスの責務を 1〜2 文で簡潔に記述する
- sealed class サブクラスは、親クラスとの関係を示す
- data class は保持するデータの意味を記述する
- private inner class で Extension Point を実装する場合、対応インターフェースに言及する

### ドキュメント改善

- 既存の記述スタイルに合わせて追記する
- 最小限の変更で品質を向上させる（過剰な加筆はしない）
