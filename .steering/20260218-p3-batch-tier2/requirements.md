# Requirements: P3 Batch Tier 2 — IDE 編集体験向上3機能

## 概要

P3 vscode ギャップ機能の実装完了後、IntelliJ 固有の編集体験向上機能3つを並列実装する。

## 対象機能

### 1. Statement Up/Down Mover
- **概要**: `Alt+Shift+Up/Down` でトップレベル宣言（let, type, module, external, open, include, exception）を上下に移動
- **ユーザーストーリー**: 開発者として、宣言の順序をキーボードだけで変更したい
- **受け入れ条件**:
  - トップレベル宣言を上下に移動できる
  - アノテーション付き宣言は一括移動される
  - ファイル先頭/末尾では移動しない
  - モジュール内宣言も移動できる

### 2. Qualified Name Copy
- **概要**: `Cmd+Shift+Alt+C` で完全修飾名（`Module.SubModule.functionName`）をコピー
- **ユーザーストーリー**: 開発者として、関数やモジュールの完全修飾名をワンアクションでコピーしたい
- **受け入れ条件**:
  - ファイル名をルートモジュール名として使用（先頭大文字化）
  - ネストされたモジュール内の要素はドット区切りのパスを生成
  - NAVIGABLE_TYPES の要素に対してのみ動作

### 3. Smart Enter
- **概要**: `Shift+Enter` で文を補完して改行（未閉じ括弧の補完、switch ブレース補完等）
- **ユーザーストーリー**: 開発者として、Shift+Enter で不完全な文を自動補完して次の行に移動したい
- **受け入れ条件**:
  - 未閉じ `{`, `(`, `[` を自動補完
  - `switch expr` 後にブレースと初期パターンを挿入
  - `| pattern` 後に `=>` を補完
  - 上記以外は通常改行

## 制約事項
- 各機能は独立しており、互いに依存しない
- 既存の PSI 構造（RescriptParser が生成するトップレベル宣言ノード）を活用する
- 共有ドキュメント更新はバッチブランチで一括実施
