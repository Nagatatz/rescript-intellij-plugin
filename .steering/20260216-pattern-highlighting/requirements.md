# Requirements: パターンマッチングハイライト

## 背景

現在の ReScript プラグインでは、パターンマッチングに関連する重要なトークンにシンタックスハイライトが適用されていない。具体的には以下のトークンが `ATTR_MAP` に登録されておらず、デフォルトのテキスト色で表示される：

- `|`（PIPE）— パターンアーム区切り / バリアント宣言
- `_`（UNDERSCORE）— ワイルドカードパターン
- `...`（DOTDOTDOT）— スプレッド演算子（配列パターン、レコードパターン）
- `::`（SHORTCUT）— リスト cons パターン

これにより、`switch` 式やバリアント型定義の視認性が低下している。

## ユーザーストーリー

- **US-1**: ReScript 開発者として、`switch` 式のパイプ `|` が視覚的に強調されることで、パターンアームの境界を素早く識別したい
- **US-2**: ReScript 開発者として、ワイルドカード `_` が目立つ色で表示されることで、キャッチオールパターンを瞬時に認識したい
- **US-3**: ReScript 開発者として、スプレッド `...` とリスト cons `::` が適切にハイライトされることで、パターンの構造を把握しやすくしたい
- **US-4**: ReScript 開発者として、Color Settings ページでパターン関連の色をカスタマイズしたい

## 受け入れ条件

1. `|` トークンがシンタックスハイライトで色付けされること（キーワード色に近い色を推奨）
2. `_` トークンが独自のハイライト色で表示されること
3. `...` トークンが演算子としてハイライトされること
4. `::` トークンが演算子としてハイライトされること
5. Darcula テーマと Default テーマの両方でカラースキームが定義されていること
6. Color Settings ページ（Settings > Editor > Color Scheme > ReScript）に新しい項目が追加されること
7. Color Settings ページのデモテキストにパターンマッチングの例が含まれること
8. ビルドが成功し、既存テストが全て通ること

## スコープ

### 含まれるもの
- `PIPE`, `UNDERSCORE`, `DOTDOTDOT`, `SHORTCUT` の 4 トークンへのハイライト追加
- `RescriptSyntaxHighlighter.kt` への TextAttributesKey 追加と ATTR_MAP 登録
- `RescriptColorSettingsPage.kt` への AttributesDescriptor 追加とデモテキスト更新
- `RescriptDarcula.xml` / `RescriptDefault.xml` へのカラー定義追加

### 含まれないもの
- レクサー（Rescript.flex）の変更（既存トークンを活用）
- パーサー（RescriptParser.kt）の変更
- LSP セマンティックトークンの変更
- パターン内のコンテキスト認識型ハイライト（レクサーレベルでは不可能）

## 制約事項

- JFlex レクサーはコンテキストフリーであるため、「パターン内の `|`」と「型定義の `|`」を区別できない。両方同じ色で統一する
- セマンティックレベルの区別は LSP セマンティックトークン（既存）に委ねる
