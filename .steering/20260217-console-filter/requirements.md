# Requirements: Console Filter

## 概要

ReScript コンパイラのエラー出力に含まれるファイルパス:行番号をクリック可能なハイパーリンクにする Console Filter 機能を実装する。

## ユーザーストーリー

**ユーザーとして**、Run/Debug ウィンドウのコンパイルエラー出力に表示されるファイルパスをクリックして、該当ファイルの該当行にジャンプしたい。

## 受け入れ条件

- [ ] コンパイルエラー出力のファイルパスがクリック可能リンクになる
- [ ] クリックで該当ファイルの該当行にジャンプ
- [ ] Run/Debug ウィンドウの出力に対して動作
- [ ] 絶対パスと相対パスの両方に対応
- [ ] ReScript コンパイラの複数のエラー出力パターンに対応

## 対応するエラー出力パターン

1. `  /path/to/file.res:10:5-15` — 絶対パス:行:列
2. `  path/to/file.res:10:5-10:15` — 相対パス:行:列-行:列
3. `  File "path/to/file.res", line 10` — OCaml 形式

## 制約事項

- `.res` / `.resi` ファイルのみを対象とする
- プロジェクトの `basePath` を基準に相対パスを解決する
