# 要求: プラットフォーム API マイグレーション調査

## 目的

プラグイン v0.1.10 時点で、IntelliJ Platform の API 変更・非推奨化の影響を調査し、今後の対応方針を決定する。

## 調査対象

1. Search Everywhere API の新アーキテクチャ（`SeItemsProvider` / `SeItemsProviderFactory`）への移行要否
2. LSP Code Lens のプラットフォームネイティブ対応状況
3. リモート開発（Gateway）環境での動作互換性
4. ReScript 新構文（dict{} 等）のレクサー対応状況
5. 大規模プロジェクトでのパフォーマンス特性

## 受け入れ条件

- [ ] 各調査項目について現状と対応方針が文書化されている
- [ ] 対応が必要な項目にタイムラインが設定されている
- [ ] 調査結果がステアリングドキュメントとしてコミットされている
