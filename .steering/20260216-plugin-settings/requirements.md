# Requirements: プラグイン設定ページ

## 概要

ReScript プラグインの集約的な設定ページを IDE の Settings ダイアログに追加する。現在、LSP サーバーパスや Node.js パスはすべて自動検出に依存しているが、ユーザーが明示的に設定を上書きできる UI を提供する。

## ユーザーストーリー

### US-PS-01: LSP サーバーパスの手動設定

**ユーザーとして**、rescript-language-server のパスを手動で指定できることで、自動検出がうまく動かない環境でも LSP 機能を利用したい。

**受け入れ条件:**
- [ ] Settings > Languages & Frameworks > ReScript に設定ページが表示される
- [ ] LSP サーバーパスをファイル選択ダイアログで指定できる
- [ ] 空欄の場合は従来の自動検出ロジックが使われる
- [ ] 設定はプロジェクト単位で保存される

### US-PS-02: Node.js パスの手動設定

**ユーザーとして**、Node.js のパスを手動で指定できることで、複数バージョンの Node.js がインストールされた環境でも正しいバージョンを使いたい。

**受け入れ条件:**
- [ ] Node.js インタープリタのパスをファイル選択ダイアログで指定できる
- [ ] 空欄の場合は PATH 上の `node` が使われる（従来動作）
- [ ] 設定はプロジェクト単位で保存される

### US-PS-03: 設定のバリデーション

**ユーザーとして**、指定したパスが有効かどうか設定画面上で確認できることで、設定ミスを防ぎたい。

**受け入れ条件:**
- [ ] 指定されたパスにファイルが存在しない場合、エラーメッセージが表示される

## 技術的制約

- IntelliJ Platform の `Configurable` API を使用する
- 設定の永続化は `PersistentStateComponent` + XML シリアライゼーションを使用する
- 設定スコープはプロジェクト単位（`ProjectConfigurable`）
- 既存の LSP サーバー起動ロジック（`RescriptLspServerDescriptor`）を設定値で上書き可能にする

## スコープ外

- アプリケーション全体（グローバル）設定は今回のスコープ外
- コードスタイル設定は既存の `langCodeStyleSettingsProvider` で対応済み
- カラー設定は既存の `colorSettingsPage` で対応済み
