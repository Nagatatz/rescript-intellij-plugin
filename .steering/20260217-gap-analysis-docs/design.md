# Design: rescript-vscode ギャップ分析の docs 追記

## 変更方針

### product-requirements.md

1. 「将来機能（ロードマップ）」セクションを以下の構造に置き換え:
   - **実装済み機能** — 既存ロードマップから実装完了した項目をリスト
   - **P1（高優先度）** — ユーザー体験に大きく影響する機能
   - **P2（中優先度）** — あると便利な機能
   - **P3（低優先度）** — nice-to-have

2. 各機能に「説明」「実装アプローチ」「難易度」を記載

### functional-design.md

1. Extension Point 登録マップに実装済みチェックマーク追加
2. 新たに登録済みの Extension Point を追加
3. rescript-vscode との機能対比表セクションを新規追加

## 影響範囲

- ドキュメントのみの変更
- コード変更なし
- ビルドへの影響なし
