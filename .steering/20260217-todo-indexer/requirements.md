# Requirements: TODO Indexer

## 概要

ReScript ファイル内のコメントに含まれる `TODO`, `FIXME` などのパターンを IntelliJ の TODO ツールウィンドウでインデクシング・表示できるようにする。

## 背景

IntelliJ は TODO ツールウィンドウ（`Cmd+6`）でプロジェクト全体の TODO コメントを一覧表示できるが、カスタム言語では `TodoIndexer` を登録しないと正しくインデクシングされない場合がある。ReScript では単一行コメント（`// TODO: ...`）と複数行コメント（`/* TODO: ... */`）の両方で TODO を検出する必要がある。

## 機能要件

### F1: TODO パターンのインデクシング

- 単一行コメント（`// TODO: ...`, `// FIXME: ...`）を検出すること
- 複数行コメント（`/* TODO: ... */`）を検出すること
- IntelliJ のデフォルト TODO パターン設定に従うこと（ユーザーがカスタムパターンを追加可能）

### F2: TODO ツールウィンドウ表示

- TODO ツールウィンドウに ReScript ファイルの TODO が一覧表示されること
- TODO 項目をクリックして該当箇所にジャンプできること

## 非機能要件

- 既存のテスト・ビルドを壊さないこと

## 受け入れ条件

- [ ] `// TODO: ...` が TODO ツールウィンドウに表示される
- [ ] `/* TODO: ... */` が TODO ツールウィンドウに表示される
- [ ] TODO 項目から該当箇所にジャンプできる
- [ ] ビルドが通る
