# 要求定義: テストカバレッジ復旧

## 背景

CI の Kover カバレッジ検証が失敗している。最低 54% のカバレッジが必要だが、実際は 9.8%。プロダクションコード 290 クラスに対しテストは 218 クラス分あるが、テスト未対応の 72 クラスのうち多くは既に Kover の excludes に登録済み。残り約 27 クラスが未除外・未テスト。

## 要求

1. テスト困難なクラス（UI, IDE ライフサイクル, Hierarchy Browser 等）を Kover の excludes に追加する
2. テスト可能なロジックを持つクラスにユニットテストを追加する
3. カバレッジ検証 (`./gradlew koverVerify`) をパスさせる（54% 以上）

## 受け入れ条件

- [ ] `./gradlew koverVerify` が成功する
- [ ] `./gradlew clean buildPlugin` が成功する
- [ ] 新規テストがすべてパスする
- [ ] 除外対象は正当な理由があるクラスのみ（UI, IDE結合, ライフサイクル依存）
