# 要求定義: リリース品質向上

## 背景

CI 自動チェックと手動チェックリストに以下のギャップがある:
- Qodana が Dependabot PR をスキップ
- リリースワークフローにバージョン整合性チェックがない
- Marketplace パブリッシュに承認ゲートがない
- 手動ルール（KDoc, テスト存在, EP 登録）の自動化がない
- セキュリティ脆弱性スキャンがない
- テストフィクスチャが4ファイルのみ
- カバレッジ閾値 54% が実測値 88% と大きく乖離

## 改善項目

### Tier 1: Quick Wins（設定変更のみ）
1.1 Qodana の Dependabot バイパス除去
1.2 リリースワークフローにバージョン整合性チェック追加
1.3 Kover カバレッジ閾値のラチェット化（54→85）
1.4 Qodana に失敗閾値を設定

### Tier 2: Gradle タスク・CI ステップ追加
2.1 KDoc 存在チェックの自動化
2.2 テストファイル存在チェックの自動化
2.3 Extension Point 登録整合性チェック
2.4 Marketplace パブリッシュ承認ゲート

### Tier 3: 長期的改善
3.1 依存関係脆弱性スキャン
3.2 テストフィクスチャの拡充
3.3 パフォーマンスベンチマーク
3.4 ヘッドレス IDE スモークテスト

## 受け入れ条件

- [ ] Tier 1〜3 の全項目が実装されている
- [ ] CI が正常にパスする（`./gradlew clean buildPlugin test`）
- [ ] release.md にラチェットポリシーが追記されている
- [ ] 新規 Gradle タスクが意図的違反時に失敗することを確認済み
