# Requirements: UI テストスクリーンショット品質修正

## 背景

UI テストフレームワーク（20260331-001）で導入したスクリーンショット自動撮影を実行したところ、以下の問題が判明した:

1. **デスクトップ背景の映り込み**: 全スクリーンショットで macOS のデスクトップ壁紙が映り込んでいる。`remoteRobot.getScreenshot()` がフルスクリーンをキャプチャしているため
2. **ファイルが正しく開かれない**: `openFileByName` が Search Everywhere ダイアログを開くが、ファイルが選択されず多くのテストで Search Everywhere ダイアログが残ったままスクリーンショットされている（03, 04, 06, 07, 09, 10）
3. **LSP 未動作**: サンプルプロジェクトに `@rescript/language-server` がインストールされていないため、LSP 依存機能（補完、インレイヒント、Code Vision、エラー診断）が動作しない
4. **REPL 未表示**: REPL ツールウィンドウが表示されていない（テスト 11）

## 目的

マーケットプレイス掲載に使える品質のスクリーンショットを生成するよう、テストコードとインフラを修正する。

## 機能要件

### FR-1: IDE ウィンドウのみのキャプチャ

- スクリーンショットは IntelliJ IDEA ウィンドウのみを撮影する（デスクトップ背景を含まない）
- `remoteRobot.getScreenshot()` の代わりに `IdeFrameFixture.getScreenshot()` を使用する

### FR-2: ファイルオープンの信頼性改善

- `openFileByName` が確実にファイルを開くよう修正する
- 考えられるアプローチ:
  - a) `runJs` で `FileEditorManager.openFile()` を直接呼ぶ（EDT 経由）
  - b) 既存のキーボードベースを改善（タイミング調整、結果確認の追加）
- ファイルが実際にエディタで開かれたことを確認してから次に進む

### FR-3: LSP 依存テストの扱い

- サンプルプロジェクトで LSP が動作しない環境でもテストがパスするよう設計する
- LSP 依存シーン（補完、Error Lens、インレイヒント、Code Vision、ホバードキュメント）について:
  - a) LSP なしでも撮影する（ネイティブ機能のみでも価値がある）
  - b) LSP がなければスキップする
  - c) サンプルプロジェクトに node_modules をセットアップするステップを追加する
- 方針: (a) — LSP なしでも基本的な見た目を撮影し、テストをグリーンに保つ

### FR-4: 各テストシーンの正確な動作

| # | シーン | 期待される状態 |
|---|--------|--------------|
| 01 | シンタックスハイライト | Demo.res がエディタで開かれ、コードがハイライトされている |
| 02 | コード補完 | Demo.res で補完ポップアップが表示されている（LSP 未動作なら基本補完） |
| 03 | Error Lens | ErrorDemo.res が開かれ、エラーがインライン表示されている（LSP 未動作ならファイル表示のみ） |
| 04 | インレイヒント | Demo.res が開かれ、型ヒントが表示されている（LSP 未動作ならコード表示のみ） |
| 05 | ストラクチャービュー | Demo.res + Structure ツールウィンドウが開いている |
| 06 | Code Vision | Demo.res が開かれている（LSP 未動作ならコード表示のみ） |
| 07 | JSX サポート | JsxDemo.res がエディタで開かれ、JSX がハイライトされている |
| 08 | Project View | プロジェクトツリーが展開表示されている |
| 09 | クイックフィックス | Demo.res で Alt+Enter メニューが表示されている |
| 10 | ホバードキュメント | Demo.res で Quick Documentation ポップアップが表示されている |
| 11 | REPL | REPL ツールウィンドウが表示されている |

## 非機能要件

- テスト全体の実行時間は 5 分以内を維持する
- テストは LSP なしの環境でも全てパスする（フレーキーテストにしない）

## 受け入れ条件

- [ ] 全スクリーンショットが IDE ウィンドウのみをキャプチャしている（デスクトップ背景なし）
- [ ] 各テストで意図したファイルがエディタに表示されている
- [ ] Search Everywhere ダイアログが残ったままのスクリーンショットがない
- [ ] 全 11 テストがパスする
- [ ] スクリーンショットの内容がマーケットプレイス掲載に適した品質である
