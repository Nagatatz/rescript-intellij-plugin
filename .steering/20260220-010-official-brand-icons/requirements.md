# Requirements: ReScript公式ブランドマークアイコンの16x16最適化

## 概要

現在のプラグインのファイルアイコン（`rescript-file.svg`, `rescript-interface.svg`, `rescript-config.svg`）を、ReScript公式ブランドマーク（赤グラデーション背景 + 白い"r"字形 + 白い丸）に置き換える。16x16ピクセルで視認性を確保しつつ、ライト/ダークテーマ両対応にする。

## 背景

- 現行アイコンは赤い角丸四角にテキスト文字を描画した簡易カスタムアイコン
- 公式ブランドマークはMITライセンスのリポジトリ（`rescript-lang/rescript-lang.org`）に含まれ、公式VSCode拡張も同様に利用している先例あり
- コアチームが「色・形を変えなければ自由に使える」と公言

## 要求事項

### 機能要件

1. **rescript-file.svg** — 公式ブランドマーク簡略版（背景パス + 白い"r"字形 + 白い丸）
2. **rescript-interface.svg** — 背景を75%透過にしたバリアント（派生ファイルであることを視覚的に示す）
3. **rescript-config.svg** — 背景に白い`{}`パスを配置（JSONコンフィグであることを明示）
4. **_dark.svg バリアント** — 上記3ファイルそれぞれにダークテーマ用バリアントを追加

### デザイン要件

- `viewBox="0 0 250 250"` + `width="16" height="16"` — 公式SVGのパスデータをそのまま使用
- フィルター・シャドウは全て除去（16x16では不可視）
- ライトテーマ: `#E84F4F` → `#DB4646` → `#CB3939`
- ダークテーマ: `#EF5E5E` → `#E04A4A` → `#D44444`（約10%明るく）

### 非機能要件

- `RescriptIcons.kt` のコード変更不要（`IconLoader` が `_dark.svg` を自動検出）
- `./gradlew buildPlugin` がパスすること

## 受け入れ条件

- [ ] 6つのSVGファイルが正しく配置されている
- [ ] ライト/ダークテーマでアイコンが適切に表示される
- [ ] ビルドが成功する
