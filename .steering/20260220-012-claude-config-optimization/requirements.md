# Requirements: Claude Code 設定最適化

## 概要

CLAUDE.md の肥大化によるトークン消費と、settings.local.json の permissions 肥大化を解消する。

## 背景

- 現在の CLAUDE.md は 500 行以上あり、毎セッションのシステムプロンプトとしてコンテキストウィンドウを圧迫している
- settings.local.json の permissions は 160 行あり、個別パスの許可が場当たり的に蓄積されている
- everything-claude-code のベストプラクティスを参考に、ルールの分離とパーミッションの整理を行う

## 要求事項

### R1: CLAUDE.md の分離

- CLAUDE.md にはプロジェクト概要・ビルドコマンド・構成図など**毎回必要な最小限の情報**のみを残す
- 開発規約（テスト規約、コメント規約、Git 規約、ステアリングワークフロー等）は `.claude/rules/` に分離する
- 分離後も既存の規約内容が失われないこと

### R2: permissions の整理

- settings.local.json の 160 行のパーミッションを、汎用的なパターンに統合する
- 不要な個別パスの許可を削除し、ワイルドカードパターンで代替する
- セキュリティ上問題のある過度な許可は行わない

## 受け入れ条件

- [ ] CLAUDE.md が 150 行以下に削減されていること
- [ ] `.claude/rules/` に分離されたルールファイルが存在すること
- [ ] settings.local.json の permissions が 30 行以下に統合されていること
- [ ] 既存の規約内容が分離先に完全に含まれていること

## 制約事項

- ステアリングワークフロー自体の内容は変更しない（分離するのみ）
- プラグインのソースコードには変更なし
