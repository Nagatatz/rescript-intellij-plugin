Inserts inferred type annotations into every un-annotated top-level let binding in the current file at once, using the types reported by the language server. For example let add = (a, b) => a + b becomes let add: (int, int) => int = (a, b) => a + b. Bindings that already have an annotation, or whose inferred type cannot be expressed as a stable annotation (weak type variables, raw types), are skipped. Useful for raising the coverage of files flagged by the Type Coverage Heat Map.
