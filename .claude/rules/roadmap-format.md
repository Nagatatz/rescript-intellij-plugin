# ロードマップ機能一覧フォーマット

`docs/product-requirements.md` の「将来機能（ロードマップ）」セクションの未実装機能一覧は、以下の統一フォーマットを使用すること。

## テーブルカラム

すべての未実装機能を以下の6カラムで記述する。カラムの追加・削除・順序変更は禁止。

```
| # | 機能 | カテゴリ | 説明 | 難易度 | 優先度 |
```

| カラム | 必須 | 説明 |
|--------|------|------|
| # | Yes | 機能の一意識別番号。既存の番号を維持し、新規追加は既存最大値 + 1 を採番 |
| 機能 | Yes | 機能名（20文字以内推奨） |
| カテゴリ | Yes | 下記の定義済みカテゴリから選択 |
| 説明 | Yes | 機能の概要（1文、60文字以内推奨） |
| 難易度 | Yes | `低` / `低〜中` / `中` / `中〜高` / `高` / `非常に高` のいずれか |
| 優先度 | Yes | `S` / `A` / `B` / `C` のいずれか |

## カテゴリ一覧

| カテゴリ | 説明 |
|---------|------|
| Intention | Alt+Enter で呼び出すコード変換アクション |
| Inspection | コード品質検査 |
| Generate | Cmd+N で呼び出すコード生成 |
| Quick Fix | エラー・警告に対する自動修正 |
| リファクタリング | コード構造の変更（動作は保持） |
| 補完 | コード補完の拡張 |
| ナビゲーション | コード間の移動・検索 |
| InlayHints | エディタ内のインラインヒント表示 |
| 分析 | コード分析・診断 |
| Editor | エディタ動作の拡張 |
| ToolWindow | ツールウィンドウ |
| インジェクション | 言語インジェクション |
| インデキシング | インデックス構築 |
| 実行 | コード実行・REPL |
| プロジェクトビュー | プロジェクトツリーの拡張 |
| Paste | ペースト時の変換処理 |
| インフラ | プラグインのインフラ・品質改善 |
| 編集 | エディタの基本編集機能 |
| その他 | 上記に該当しないもの |

## 優先度定義

| 優先度 | 説明 |
|--------|------|
| S | 最優先 — ユーザー価値が高く、次に実装すべき機能 |
| A | 重要 — 開発体験を大きく向上させる機能 |
| B | 有用 — あると便利だが緊急性は低い機能 |
| C | 将来検討 — 低優先度、高難度、またはニッチな用途の機能 |

## 並び順

テーブル内の行は以下の順序で並べる:

1. 優先度順: S → A → B → C
2. 同一優先度内は `#` の昇順

## 更新ルール

- **実装着手時:** 該当行の `#` カラムに 🚧 マークを付加する（例: `🚧 44`）。これにより、現在実装中の機能が一目で分かる
- **実装完了時:** 🚧 マークを外し、該当行を「将来機能」テーブルから削除して「実装済み機能」セクションに移動する
- **新規追加時:** `#` は既存最大値 + 1 を採番し、適切な優先度に分類する
- **優先度変更:** 見直し時に優先度を変更してよい
- **実装不要と判断時:** 行を削除し、理由を記載する
