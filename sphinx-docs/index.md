# ReScript IntelliJ Plugin

Full-featured [ReScript](https://rescript-lang.org) language support for IntelliJ IDEA and other JetBrains IDEs.

This plugin combines a fast, built-in JFlex lexer for syntax highlighting with the official [ReScript Language Server](https://github.com/rescript-lang/rescript-vscode) (LSP) for semantic features — giving you the best of both worlds.

## Highlights

- **Syntax highlighting** — JFlex lexer with semantic token overlay from LSP
- **Code completion** — Intelligent completions via LSP
- **Navigation** — Go to Definition, Symbol, Related files
- **Diagnostics** — Real-time errors and warnings
- **60+ features** — Run configs, testing, code analysis, and more
